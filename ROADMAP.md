# ORIGIN Roadmap

This roadmap describes direction rather than fixed delivery dates. Features move forward only when their tests, data provenance, and risk boundaries are clear.

## v0.1 — Genesis

- [x] Rust workspace
- [x] Deterministic candidate generator
- [x] Preliminary structural score
- [x] Table and JSON CLI output
- [x] Unit tests and continuous integration
- [ ] External phoneme configuration
- [ ] Streaming generation for million-scale runs
- [ ] CSV and JSON Lines export
- [ ] Benchmarks

## v0.2 — Selection

- [ ] Weighted phonetic rules
- [ ] Configurable forbidden terms and patterns
- [ ] Syllable and pronunciation heuristics
- [ ] Candidate deduplication at scale
- [ ] Edit-distance similarity engine
- [ ] Reference-brand dataset format
- [ ] Explainable score breakdown

## v0.3 — Evolution

- [ ] Mutation and crossover operators
- [ ] Population-based search
- [ ] User preference feedback
- [ ] Diversity preservation
- [ ] Reproducible experiment manifests

## v0.4 — Validation

- [ ] Domain availability adapters
- [ ] GitHub repository and organization checks
- [ ] Public web collision research
- [ ] Trademark database adapters
- [ ] Evidence snapshots and timestamps
- [ ] Risk reports with explicit uncertainty

Automated validation will remain a preliminary risk screen. It will not claim legal clearance or replace professional trademark advice.

## v0.5 — Product

- [ ] Local desktop application
- [ ] Candidate comparison workspace
- [ ] Review queues and annotations
- [ ] Exportable research reports
- [ ] Community and professional feature boundaries
