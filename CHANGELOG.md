# Changelog

All notable changes to Origin are documented in this file.

## Unreleased — 1.1.0-alpha.1

### Changed

- Replaced the small synthetic name-fragment list with a compositional phonetic
  space of more than 294 million two- and three-syllable constructions.
- Kept the 10,000-candidate CLI ceiling as an output limit only; it is no
  longer described or implemented as the candidate-pool size.
- Historical roots remain inspiration inputs and are transformed before use in
  ancient-inspired and hybrid candidate construction.

## 1.0.0 — 2026-08-09

### Added

- Deterministic four-strategy brand design with up to 10,000 candidates.
- Source-attributed semantic roots from Latin, Sumerian, Akkadian, Old Turkic,
  and Sanskrit traditions.
- Evidence-backed availability reports for public developer registries,
  exact-name company/web sources, and standard domain TLDs.
- Conservative finalist recommendations: clear, provisional, or rejected.
- Full JSON audit output for every candidate in the finalist screening pool.

### Quality and documentation

- Phone-friendly spelling gate and accepted-quality-only design pool.
- Release criteria, capability matrix, and data-provenance policy.
- Deterministic tests, linting, formatting, and API documentation gates.

### Important boundary

Origin's availability and deterministic trademark-risk features are decision
support. They are not a legal trademark clearance opinion.
